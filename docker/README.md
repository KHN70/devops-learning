# Docker Learning & Progression

This directory contains my hands-on labs, exercises, and architectural challenges as I master containerization, multi-container orchestration, and infrastructure tooling.

## 📁 Directory Structure

- **`hello_flask/`**: Introductory labs focused on containerizing a basic Python Flask application, writing custom Dockerfiles, managing dependencies (`requirements.txt`), and building images.
- **`challenge/`**: An advanced multi-container microservice project featuring Nginx load balancing, scaled stateless Flask workers (`--scale web=3`), and a persistent Redis database backed by Docker volumes.
