# Linux & Bash Scripting

This directory contains practical Bash scripting exercises, challenges, and interactive projects built as part of my DevOps learning path.

## Repository Structure

* [**bash-scripting/**](./bash-scripting/) — Core automation scripts covering arithmetic, file system checks, defensive programming, and automated backups.
* [**bash-battle-arena/**](./bash-battle-arena/) — Interactive CLI scripting exercises and gamified scenarios.

## Core Concepts Covered
* Shell execution modes (`./script.sh`, `bash`, `source`)
* Exit statuses (`$?`) and defensive error handling (`set -euo pipefail`)
* File permission and existence tests (`-f`, `-d`, `-r`, `-w`, `-x`)
* Command substitution (`$(...)`) and pipelines (`ls -1 | wc -l`)
* Git artifact filtering using `.gitignore`
