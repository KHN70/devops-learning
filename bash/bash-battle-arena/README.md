# Bash Battle Arena ⚔️

A hands-on, gamified Linux shell challenge designed to build fluency in command-line navigation, file analysis, text processing pipelines, and system administration essentials.

## Progress Overview

- **Current Status:** Completed Levels 1–7
- **Environment:** Ubuntu / Linux Shell (`bash`)

---

## Completed Arena Levels

| Level | Topic / Objective | Key Tools & Commands |
| :--- | :--- | :--- |
| **Level 1** | Filesystem Navigation & Discovery | `pwd`, `cd`, `ls -la` |
| **Level 2** | File Type Inspection & Inspection | `cat`, `head`, `tail`, `file`, hidden dotfiles |
| **Level 3** | Text Searching & Pattern Matching | `grep`, `grep -rn`, regex pattern filters |
| **Level 4** | Data Sorting & Frequency Analysis | `sort`, `uniq -c`, pipeline chaining |
| **Level 5** | Field Delimitation & Column Filtering | `cut -d`, `awk`, `tr` character replacements |
| **Level 6** | I/O Redirection & Stream Chaining | Standard streams (`stdin`, `stdout`, `stderr`), `|`, `xargs` |
| **Level 7** | File Permissions & Executable Auditing | `chmod`, `ls -l`, read/write/execute permission bits |

---

## Key Takeaways

* **Pipeline Efficiency:** Combining single-purpose utilities (`grep | sort | uniq -c`) to parse unstructured system logs and text payloads.
* **Defensive Shell Interaction:** Understanding file permissions, executable bits, and clean stream redirection (`2>/dev/null`) to handle edge cases without cluttering shell output.
* **Rapid Command-Line Navigation:** Leveraging shell shortcuts, wildcard expansion, and globbing to inspect nested directory structures quickly.
